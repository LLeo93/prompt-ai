# 🚀 Prompt AI Manager

**Prompt AI Manager** è un’applicazione web sviluppata con **React, Redux, TypeScript e Tailwind CSS** che ti permette di gestire i tuoi prompt AI in maniera semplice e veloce.

L’interfaccia è intuitiva e responsive: puoi generare prompt, salvarli tra i preferiti, modificarli, esportarli e importarli in formato JSON.

---

## 🖥️ Tecnologie

- **React 19**
- **Redux Toolkit**
- **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion** (animazioni)
- **React Router Dom** (routing)
- **SweetAlert2** (alert personalizzati)
- **UUID** (identificatori unici)
- **Vite** (bundler moderno)
- **React Icons** (icone)

---

## ✨ Funzionalità

- Creazione di prompt personalizzati per AI.
- Salvataggio dei prompt preferiti.
- Modifica e aggiornamento dei prompt esistenti.
- Esportazione e importazione dei prompt in formato JSON.
- Interfaccia responsive, adatta a desktop e mobile.
- Animazioni interattive con **Framer Motion**.
- Notifiche e conferme con **SweetAlert2**.
- Ricerca e filtro tra i prompt salvati (ora funzionante).
- Organizzazione dei prompt tramite categorie o tag (ora funzionante).

## 📦 Installazione e avvio

Assicurati di avere installato Node.js e npm.
