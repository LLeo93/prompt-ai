# 🚀 Prompt AI Manager

**Prompt AI Manager** è un’applicazione web sviluppata con **React, Redux, TypeScript e Tailwind CSS** che ti permette di gestire i tuoi prompt AI in maniera semplice e veloce.

L’interfaccia è intuitiva e responsive: puoi generare prompt, salvarli tra i preferiti, modificarli, esportarli e importarli in formato JSON.

---

## 🖥️ Tecnologie

- **React 19**
- **Redux Toolkit**
- **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion** (animazioni)
- **React Router Dom** (routing)
- **SweetAlert2** (alert personalizzati)
- **UUID** (identificatori unici)
- **Vite** (bundler moderno)
- **React Icons** (icone)

---

## ✨ Funzionalità di PromptLab

PromptLab è la tua applicazione completa per creare, gestire e salvare prompt per intelligenze artificiali. Le principali funzionalità includono:

- **Creazione di prompt personalizzati** per AI.
- **Salvataggio dei prompt preferiti** per un accesso rapido.
- **Modifica e aggiornamento dei prompt esistenti**.
- **Esportazione e importazione dei prompt** in formato JSON.
- **esportare ogni singolo prompt** con un pulsante dedicato.
- **Interfaccia responsive**, ottimizzata per desktop e mobile.
- **Animazioni interattive** con **Framer Motion** per un’esperienza più dinamica.
- **Notifiche e conferme** con **SweetAlert2**.
- **Ricerca e filtro tra i prompt salvati** .
- **Organizzazione dei prompt tramite categorie o tag** .
- **Guida integrata** con descrizioni accurate su come utilizzare tutte le funzionalità.

Assicurati di avere installato Node.js e npm.

1. Clona il progetto:

bash

Installa le dipendenze:

Avvia il progetto in sviluppo:

L’applicazione sarà disponibile su http://localhost:5173
